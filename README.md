# Lexara: Automated Podcast Analysis Platform

**Lexara** is an industry-grade automated transcription and topic segmentation system designed to transform raw podcast audio into structured, searchable, and insight-driven content. Leveraging state-of-the-art machine learning models, Lexara provides a premium dashboard experience for content consumption and analysis.

## 🚀 core Features

- **High-Accuracy Transcription**: Powered by OpenAI's Whisper (Large-v3 model) for near-perfect speech-to-text.
- **Dynamic Topic Segmentation**: Utilizing SBERT (Sentence-BERT) and similarity-based chunking to identify logical conversation shifts.
- **Intelligent Summarization**: Context-aware segment summaries generated by the T5 Transformer model.
- **Interactive Visual Timelines**: Color-coded horizontal timelines for quick navigation based on segment sentiment.
- **Sentiment Analysis**: VADER-powered emotional tone detection for every segment (Positive, Negative, Neutral).
- **Global Search**: Instant keyword and content search across the entire podcast library.
- **Premium Dark UI**: A modern, responsive dashboard with a distinctive purple dark theme.

## 🛠 Tech Stack

- **Backend**: Python, Flask, NLTK, Transformers (Hugging Face), PyTorch.
- **Frontend**: React.js, Vite, Tailwind CSS, Framer Motion, Axios.
- **Models**: Whisper (ASR), SBERT (Segmentation), T5 (Summarization), VADER (Sentiment).

## 📦 Installation

### Prerequisites
- Python 3.10+
- Node.js 18+
- FFmpeg (required for audio processing)

### Backend Setup
1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd automated-podcast-analysis
   ```
2. Create and activate a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

### Frontend Setup
1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```

## 🎮 Usage

### 1. Processing Podcasts
Place your audio files in `data/raw/` (or use the metadata URLs) and run the processing pipeline:
```bash
python run_week3.py
```
*Note: This will perform transcription, segmentation, and analysis.*

### 2. Starting the Backend Server
```bash
python app.py
```
The API will be available at `http://localhost:5000`.

### 3. Running the Dashboard
```bash
cd frontend
npm run dev
```
Open `http://localhost:5173` in your browser.

## 📂 Project Structure

- `src/`: Core service modules (ASR, Segmentation, Sentiment).
- `data/`: Storage for raw audio, transcripts, and final segmented JSONs.
- `frontend/`: React application code.
- `app.py`: Flask API entry point.
- `run_week3.py`: Main processing pipeline.
